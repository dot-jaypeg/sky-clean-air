Simple tips to keep air cleaner between visits

  • Replace filters every 1 to 3 months based on usage and pets
  • Keep return grilles clear of furniture and dust
  • Run the fan on low during cleaning or vacuuming to catch extra dust
  • After kitchen or bathroom work, vacuum those rooms and run the system fan for a bit
  • During wildfire smoke days, keep windows closed and run a higher MERV filter if your system supports it

If you are not sure which filter your system can handle, we will check static pressure and recommend a safe option.
